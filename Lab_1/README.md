# Лабораторная работа №1 — Цветовые модели

Интерактивный сайт на TypeScript для работы с цветовыми моделями **RGB**, **CMYK** и **HLS**.
В работе используется нечётный вариант: CMYK — RGB — HLS.

## Возможности

- точный ввод каждой компоненты числами;
- плавное изменение компонентов ползунками;
- выбор через системную палитру и HEX;
- автоматический пересчёт всех моделей после любого изменения;
- предпросмотр итогового цвета;
- адаптивный интерфейс для компьютера и телефона.

## Запуск

```bash
npm install
npm run dev
```

Проверка преобразований и production-сборка:

```bash
npm test
npm run build
```

## Формулы преобразований

Внутри приложения текущий цвет хранится в RGB. При изменении другой модели она сначала преобразуется в RGB, после чего из нового RGB рассчитываются остальные представления.

### RGB → CMYK

Сначала `R`, `G`, `B` переводятся в диапазон `[0; 1]`.

```text
K = 1 - max(R, G, B)
C = (1 - R - K) / (1 - K)
M = (1 - G - K) / (1 - K)
Y = (1 - B - K) / (1 - K)
```

Для абсолютно чёрного цвета: `C = M = Y = 0`, `K = 1`.

### CMYK → RGB

```text
R = 255 × (1 - C) × (1 - K)
G = 255 × (1 - M) × (1 - K)
B = 255 × (1 - Y) × (1 - K)
```

### RGB ↔ HLS

Сначала находятся максимальная и минимальная RGB-компоненты и их разность. Тон `H` определяется сектором цветового круга. Светлота `L` равна среднему между максимумом и минимумом, а насыщенность рассчитывается относительно светлоты.

- `src/styles.css` — оформление и адаптивность;
