# Лабораторная работа №3 — базовые растровые алгоритмы

Простое веб-приложение на TypeScript и Canvas API для демонстрации обязательных алгоритмов из задания:

- пошаговый алгоритм построения отрезка;
- алгоритм ЦДА;
- алгоритм Брезенхема для отрезка;
- алгоритм Брезенхема для окружности.

В приложении есть интерактивный ввод целочисленных координат, масштаб сетки, оси, подписи координат, идеальная геометрическая линия, выбранные растровые клетки, промежуточные вычисления, список координат пикселей и сравнение времени реализации всех методов.

## Запуск

```bash
npm install
npm run dev
```

Проверка:

```bash
npm test
npm run build
```

## Привязка к дискретной сетке

Клетка с целочисленными координатами `(x, y)` имеет центр в точке `(originX + x * scale, originY - y * scale)` на Canvas. `scale` — размер одной клетки в пикселях. Ось Y инвертируется, потому что в Canvas экранные координаты растут вниз. Алгоритмы выбирают только целые координаты, поэтому каждая выбранная пара `(x, y)` закрашивает одну клетку сетки.

Время в интерфейсе считается как среднее значение 1000 запусков выбранной функции построения на текущем наборе входных данных. Это позволяет увидеть даже очень короткие операции и не включает отрисовку Canvas.
