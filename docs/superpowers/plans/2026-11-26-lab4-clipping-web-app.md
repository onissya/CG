**Goal:** Добавить в репозиторий рабочее веб-приложение только для двух заданий варианта 17 лабораторной работы №4 и отчёт в стиле предыдущих лабораторных.

Приложение показывает координатную сетку, окно отсечения, исходные примитивы и видимые результаты для отрезков и выпуклого многоугольника. Другие варианты алгоритмов не добавляются.

## Global Constraints

- Лабораторная №4 должна быть веб-приложением, иллюстрирующим алгоритмы отсечения отрезков и многоугольников.
- Входные данные включают набор отрезков и координаты отсекающего прямоугольного окна `Xmin Ymin Xmax Ymax`.
- Для варианта 17 используется алгоритм Лианга–Барски для отрезков.
- Для нечётного варианта 17 используется отсечение выпуклого многоугольника алгоритмом Сазерленда–Ходжмана.
- Алгоритмы Сазерленда–Коэна и средней точки, а также иные варианты задания в приложение не входят.
- Нужно показать систему координат, окно одним цветом, исходные примитивы другим цветом и визуализировать видимые части.
- Отчёт повторяет структуру предыдущих работ: цель, задачи, ход работы, алгоритмы/псевдокод, результат, вывод.
- Изменения должны быть минимальными и не добавлять внешние библиотеки для самих алгоритмов.

## Review Focus

- Отрезок полностью вне окна — результатом должен быть `null`/невидимая часть.
- Отрезок пересекает каждую из четырёх границ — параметрические границы должны корректно ограничиваться.
- Вертикальные, горизонтальные и вырожденные отрезки — не должно быть деления на ноль или пропуска конечных точек.
- Вершины выпуклого многоугольника на границе окна — результат не должен содержать `NaN` и лишние точки.
- Обратный порядок координат окна и пустой ввод — интерфейс должен нормализовать окно или показать понятную ошибку.
