# Лабораторная работа №2 — вариант 17

Веб-приложение на TypeScript для обработки изображений средствами Canvas API.

## Реализовано

- средний низкочастотный фильтр;
- гауссов низкочастотный фильтр;
- морфологические операции: эрозия, дилатация, открытие и закрытие;
- квадратные окна 3 × 3 и 5 × 5;
- три встроенных тестовых изображения и загрузка пользовательского файла;
- простые метрики диапазона и стандартного отклонения;
- сравнение изображения до и после обработки.


Все алгоритмы реализованы вручную в `src/algorithms.ts`, без библиотек обработки изображений.

## Запуск

```bash
npm install
npm run dev
```

После запуска откройте адрес, показанный Vite (обычно `http://localhost:5173`).

## Проверка

```bash
npm test
npm run build
```
