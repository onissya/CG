# Лабораторная работа №4 — алгоритмы отсечения

Вариант 17. В приложении реализованы только два задания из методички:

- алгоритм Лианга–Барски для отсечения отрезков прямоугольным окном;
- алгоритм Сазерленда–Ходжмана для отсечения выпуклого многоугольника.

## Запуск

```bash
npm install
npm run dev
```

Если используется pnpm:

```bash
pnpm install
pnpm run dev
```

После запуска откройте адрес Vite, обычно `http://localhost:5173`.

## Проверка

```bash
npm test
npm run build
```

В интерфейсе можно изменить координаты окна, список отрезков или вершины выпуклого многоугольника. Canvas показывает координатную сетку, исходную геометрию и видимую после отсечения часть.
